## 🔧 第 13 轮（2026-09-26，百度网盘客户端上传实测）—— Read 显示图≠物理坐标 & 上传对话框必须真实选中

**本机环境**：百度网盘装在 `D:\BaiduNetdisk\`，客户端本地服务 127.0.0.1:8475（baidunetdiskhost，400 Bad Request，无开放 API 可用）。

1. **Read 工具显示截图时会把大图缩小，读出来的坐标不是物理坐标！** 3096x2064 的 mss 截图在 Read 里显示为 ~1080 宽，目测按钮位置要乘 2.867（屏宽/显示宽）才是物理坐标。**对策：坐标一律用 `locate-text`/`click-text` 的 OCR 返回值，别用肉眼看图估**——本轮靠目测连点三次"存入"全点空。快速心算：显示坐标 × (3096/1080 ≈ 2.87)。
2. **客户端 splash 会卡死在"启动中"**（长挂后台后）：mss 全屏截图窗口区域全黑 + shot-pw 也黑 = 真没渲染。对策：`taskkill /F /IM BaiduNetdisk.exe`（连带 Unite/host）→ `explorer.exe "D:\BaiduNetdisk\BaiduNetdisk.exe"` 重启，12 秒内出主界面（已登录则免登录）。
3. **上传对话框（"请选择文件/文件夹"，按钮叫"存入百度网盘"）手输完整路径无效**：在文件名框输入 `D:\path\file.zip` 后点"存入"或回车，对话框关闭但**不创建任何上传任务**（传输列表为空、目标文件夹为空），静默失败。
   ✅ **正解**：文件名框输入目录路径（如 `D:\up`）回车**导航** → 在文件列表**单击选中文件**（文件名框自动填入文件名）→ 再点"存入百度网盘" → 成功，右下角弹"xx上传完成"通知。
   （D:\ 根目录在对话框里只渲染出 1 个文件夹，列表渲染有 bug；导航进子目录就正常。）
4. **文件夹可以重命名，文件重命名不生效**（右键→重命名→输入→回车/点空白，文件名纹丝不动，重试 3 次均失败）。要改文件名：**本地先改好名再上传**，比在客户端里死磕快。
5. **上传成功后"上传文件"大按钮消失**（那是空文件夹专属），后续上传用**左侧工具栏"上传"按钮**。上传完成通知的 × 按钮约在 (2992,1454)。
6. 对话框里**多选文件（ctrl+click）做不了**——mc.py 的 click 不支持按住修饰键点击，`hotkey ctrl` 单发不保持。多文件就分多次上传，每次"选中→存入"。
7. **坐标验证三板斧**（本轮实战流程）：`click-text` 拿 OCR 坐标点按钮 → 裁剪 region 截图核对输入框内容 → 全屏截图验证操作生效。点完必验，别连点（连点两下可能开了又关）。
