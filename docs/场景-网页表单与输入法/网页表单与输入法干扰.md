## 🔧 第 10 轮（2026-09-16，微信公众平台注册页实操）—— 运行框输入 + 前台锁两条硬经验

1. **路径必须用 native 盘符**：在 WorkBuddy Bash 里调托管 venv 的 `python.exe`、或给 `mc.py --out` 传路径时，一律用 `C:/…` `D:/…` 开头。MSYS 的 `/c/Users/…` 会被原生 python 当相对路径拼成 `d:\c\Users\…`，直接 `can't open file`。（同理技能根目录/脚本路径也一样。）
2. **`mc.py type` 有时回退 `pyautogui.write`，在中文输入法键位下会把 `/ :` 打成中文标点**（本轮 `https://mp.weixin.qq.com/` 被打成 `、https://…`，运行框直接报 "Windows 找不到文件"）。
   - 判据：看返回体 `"method"` 字段 —— `clipboard` 才可靠，`write` 就要警惕。
   - 正确姿势（用"运行"框开网页）：`hotkey win,r` → 点一下输入框 → `hotkey ctrl,a` → `key delete` → `type`（确认 method:clipboard）→ **截图核对内容** → 再 `key enter`。
3. **前台锁：`win-activate` 返回 `is_foreground:false` 时 OCR 会读错窗口（读到被抢到前台的 WorkBuddy），但 SendInput 点击仍落到光标下的窗口。**
   - 也就是"激活失败 ≠ 点不动"：`locate-text` 找不到时，可信上一张 mss 全屏截图目测坐标 + 直接 `click`，再用 mss 截图验收；不必强求激活成功。若要点得稳可 `shot-pw --hwnd` 先看目标真实内容。
4. **微信小程序注册导航路径（可复用）**：`mp.weixin.qq.com` → 右上「立即注册」→ 选「小程序」卡片 → 「前往注册」→ ①账号信息。注意：**营业执照在 ②信息登记 那一步，不在 ①账号信息**（①只填邮箱+密码）。
