## 🔧 第 12 轮（2026-09-19，微信云开发开通页实操）—— PrintWindow 会骗你 & 点开的可能是独立窗口

1. **🚨 `shot-pw`（PrintWindow）会返回缓存帧，"没变化"可能是假象。**
   实测：点"取消"成功关掉了弹窗，但 `shot-pw` 抓出来弹窗**还在**（与上一张二进制完全相同，`black:false`）。
   以为是点击没生效，白试了两轮。改用 `batch` 内 `win-activate`+**mss 全屏 `shot`** 才看到真实状态（弹窗已关）。
   → **铁律：判断"操作生效没"用 `{"op":"win-activate","hwnd":X},{"op":"shot","out":"D:/x.png"}` 的 mss 全屏图**（同一 batch 内 WorkBuddy 来不及抢前台）；`shot-pw` 只负责"看清内容"。§0.5.4 第 4 条已同步修正。
2. **点开的可能是"独立窗口"，抓主窗口当然啥都看不到。**
   微信开发者工具点顶部云朵「云开发」→ 弹出**独立窗口**「云开发控制台 v2.0.3」（类名 `Chrome_WidgetWin_0`，pid 与 DevTools 相同）。
   一直抓 DevTools 主窗，毫无变化，误判"按钮点不动"。
   → **对策①**：点击后立刻 `win-list` 找新窗口（按标题关键字过滤）。
   → **对策②（更准）**：`WindowFromPoint(x,y)` + `GetForegroundWindow()` 直接问系统"我点的位置现在是谁、前台是谁"。本轮就是靠它一眼发现"云开发控制台早就打开了"，且拿到的正是它自己的 hwnd。
   ```python
   import ctypes
   u = ctypes.windll.user32
   class POINT(ctypes.Structure): _fields_=[('x',ctypes.c_long),('y',ctypes.c_long)]
   h = u.WindowFromPoint(POINT(2272,25)); root = u.GetAncestor(h,2)
   b = ctypes.create_unicode_buffer(512); u.GetWindowTextW(root,b,512); print(b.value)
   ```
   注：被完全盖住的窗口，`win-list` 里也是 `visible:true`；坐标探测是最快的确认手段。
3. **`batch` 里 `type` op 会让整个 batch 失败**（exit 1、连 JSON 都不输出）。把 `activate / click / type / shot` **拆成多条独立 `mc.py` 命令**跑即可（type 单跑正常，返回 `method:"clipboard"`）。
4. **`mc.py type` 打进网页输入框后**，截图底部多出一个搜狗输入法候选**黑框**，会盖住页面底部的按钮。`mc.py key --key esc` 关掉即可。
5. **定位小图标别靠目测缩略图**：自己给裁剪放大图**画坐标刻度线**（每 100 原图像素一条 + 标数值），读图时坐标一瞄就准。目测 1080 缩略图换算到 3096 物理宽，误差可达 300px（本轮实测：云开发云朵图标实际 x≈2272，目测换算出 2623，正好点空）。
6. **微信开发者工具「云开发」实操路径（2026-09-19 全程零接手跑通一个真项目）**：
   - 顶部工具栏那个**云朵图标**就是「云开发」入口（3096 宽屏下约 x=2272,y=25），点开弹**独立窗口**「云开发控制台 v2.0.3」（类名 `Chrome_WidgetWin_0`）——别傻等主窗口变化。
   - 左侧菜单项间距约 90px（概览 261 / 运营分析 352 / 数据库 442 / 存储 531 / 云函数 623 / AI 711）；菜单字小，**用 `mc.py ocr --region 60,150,280,780` 先拿准坐标再点**。
   - **改云函数超时**：左侧「云函数」→ 目标函数行点「版本与配置」→ 版本表点「配置」→ 展开「高级配置」→ **「执行超时」的数字框可直接点击后 `ctrl+a` 输入**（3 改 60），**不用猛点 ⊟/⊕**。改完点「确定」，再用 `cli cloud functions info` 验证。
   - **建数据库集合**：左侧「数据库」→ 集合名右边「+」→ 填名字 → 权限类型下拉选「仅创建者可读写」→「创建」。
   - **改项目里 `config.js`/`app.json` 之类后，必须 `Ctrl+B` 重新编译小程序才生效**，否则改了等于没改。
   - 云函数的「云端测试」面板**交互不可靠**（点「运行测试」结果区常不刷新）→ **要验证就老实走小程序模拟器**，那才是真链路。
   - 模拟器端到端验证：点输入框（连点两次防吞）→ `type`（剪贴板）→ 点「开始提取」→ 等 30~60 秒（视频要转存）→ **看「剩余次数」有没有减 1，那是全链路成功的铁证**。
7. **微信开发者工具 CLI（`cli.bat`）能做很多 GUI 的活**（省掉大量点击）：
   - `cli cloud env list --project <路径>` 查环境ID；`cli cloud functions info --env <ID> --names <名> --project <路径>` 查函数状态/超时
   - `cli cloud functions deploy --env <ID> --names a b --project <路径> -r` 部署（`-r` = 云端装依赖）
   - `cli cloud functions download --env <ID> --name <名> --path <目录> --project <路径>` 把**云端真实文件**拉下来核对（排障神器）
   - 部署后**云端生效有延迟**，刚部署完立刻下载/测试可能拿到旧版本，**等 20~30 秒**再验。
